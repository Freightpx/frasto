# Code of Conduct

## Our standard

We want this project to be a constructive place for designers and developers to collaborate. Be respectful, specific, and generous when discussing code, design, accessibility, and product decisions.

Unacceptable behavior includes harassment, discrimination, threats, deliberate disruption, or publishing another person's private information without permission.

## Scope

These expectations apply in project repositories, issue discussions, pull requests, community spaces, and public interactions representing the project.

## Enforcement

Project maintainers may edit, remove, or reject contributions and participation that violate these expectations. Serious or repeated violations may result in a ban from project spaces.
