# Implementation Ideas

A simple parking lot for ideas that may improve Frasto. Adding an idea here does not commit it to the roadmap. Move it into the roadmap only after its value, scope, and priority have been reviewed.

Use `- [ ]` for an idea that is not implemented and `- [x]` after it has been implemented.

- [ ] **Theme builder** — Create an interactive playground and theme generator, similar in purpose to daisyUI's theme tools, for editing Frasto semantic tokens and previewing components before exporting a theme configuration.
- [ ] **AI skills integration** — Provide Frasto-focused skills or structured guidance that helps AI coding tools discover components, follow Frasto conventions, and generate compatible Astro interfaces.
- [ ] **Donations and support** — Add a transparent way for individuals and organizations to financially support Frasto's open-source development and maintenance.
