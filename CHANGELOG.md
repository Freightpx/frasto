# Changelog

Notable user-facing changes to Frasto will be recorded here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and releases follow [Semantic Versioning](https://semver.org/).

## Unreleased

## [0.1.0-alpha.1] - 2026-09-03

### Added

- Public-alpha package containing 35 Experimental component families, including ThemeSwitch and Toast.
- Rendered semantic contracts, Chromium/Firefox/WebKit behavior coverage, accessibility scans, responsive evidence, and packed Astro consumer validation.
- Frasto UI AI skill starter and public integration guidance.
- Six square Spinner variants: orbit, breathe, cascade, counter, typewriter, and refresh.

### Changed

- Repositioned Frasto as a broadly reusable open-source UI component library and design system.
- Hardened Dialog and Drawer backdrop, focus-return, and nested-safe document scroll behavior.
- Published public-alpha installation, compatibility, support, and release documentation.
- Unified the public website and documentation navigation, with a compact showcase of all 35 families.

### Fixed

- Preserved automatic Frasto tokens and component styles when consumers use named imports from the flat package entry.
- Kept public documentation status banners readable at narrow viewports.
- Corrected brand contrast across themes and Spinner animation direction and leader contrast.
