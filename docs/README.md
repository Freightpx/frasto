# Frasto Development Documentation

This directory contains project and contributor documentation for developing Frasto itself. It is intentionally separate from the consumer documentation in `apps/web/src/content/docs/docs`.

## Documentation boundaries

| Area | Audience | Contents |
| --- | --- | --- |
| Public documentation | Frasto users | installation, configuration, foundations, implemented components, and usable guides |
| Project documentation | maintainers and contributors | product direction, roadmap, idea intake, and ecosystem decisions |
| Development documentation | contributors | architecture, design rules, component standards, testing, and releases |
| Specifications | maintainers and implementers | planned APIs, patterns, and future application-layer research |
| Archive | historical reference | superseded handoffs and decisions that are no longer executable plans |
