# Content and Copy

Frasto copy is concise, specific, and operational. It helps people understand where they are, what changed, and what they can do next.

## Voice

- direct, not abrupt
- confident, not promotional
- friendly, not chatty
- technical when precision helps
- calm in warnings and errors

## Labels

Use familiar nouns for navigation and clear verbs for actions.

| Prefer | Avoid |
| --- | --- |
| Save changes | Submit |
| Add customer | Create new |
| Delete invoice | Yes, delete it |
| No customers yet | Nothing here! |

## Headings

Keep page titles short. Use an eyebrow or description for context instead of turning the title into a sentence.

```text
CUSTOMERS / CRM

Customers

Manage customer relationships and account activity.
```

## Empty and error states

State what happened, preserve available context, and offer a relevant next action. Do not blame the user or use humor where data loss, access, or billing may be involved.

## Destructive actions

Name the affected object and consequence. Confirmation language should distinguish reversible removal from permanent deletion.

## Localization

Avoid composing sentences from separate fragments. Allow labels to grow, keep date and number formatting out of component internals, and do not encode meaning through English-specific capitalization.
