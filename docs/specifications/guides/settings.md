---
title: Build settings
description: Create clear settings navigation, forms, save states, and permission boundaries.
---

## 1. Group by task

Use sections people recognize: General, Profile, Team, Security, Notifications, Billing, and API. Keep the number of primary destinations scannable.

## 2. Choose route boundaries

Long or permission-sensitive settings usually benefit from separate URLs. Preserve current location in navigation and browser history.

## 3. Compose form sections

Each section has a heading, concise description, related fields, and one consistent save model. Keep line length and form width comfortable.

## 4. Define save behavior

Explicit save works for related changes. Immediate update works for small reversible settings. Communicate submitting, saved, and failed states and preserve input on failure.

## 5. Separate danger

Account deletion, key revocation, and irreversible actions belong in a clearly separated region with consequence-focused confirmation.

## 6. Transform navigation

On narrow screens, use a select, drawer, or compact navigation that keeps the current section and return path clear.
