## Current phase

**Documentation-first foundation.**

The repository currently establishes:

- product scope
- design principles
- semantic color direction
- typography hierarchy
- spacing and shape rules
- motion and accessibility baselines
- server-first architecture
- package boundaries
- initial component roadmap

## Not ready yet

The UI package is not production-ready. Component APIs should be considered unstable until the first alpha.

## Alpha target

`0.1.0-alpha` should include the first coherent primitive set, documentation, a reference SaaS screen set, accessibility checks, and an installable package.
