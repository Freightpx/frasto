---
title: Shadows
description: Elevation reserved for surfaces that genuinely overlap other content.
---

Frasto does not use shadow as the default way to create hierarchy. Typography, spacing, border, and surface contrast come first.

## Appropriate uses

- dropdowns and popovers
- dialogs and mobile drawers
- sticky controls crossing content
- temporary floating feedback

## Inappropriate uses

- every card on a dashboard
- static page sections
- table rows
- nested surfaces that already have borders

## Elevation model

Use the smallest shadow that communicates overlap. A raised surface should also have an appropriate border so its edge remains visible in high-contrast and dark themes.

## Accessibility

Never rely on shadow alone to distinguish an interactive boundary. Shadows can disappear under custom contrast settings and are difficult to perceive for some users.
