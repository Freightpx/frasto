Guides explain decisions that span several components or connect Frasto to application code.

## Application guides

- build a SaaS dashboard
- structure a CRM
- build a settings area
- handle tables and data states
- compose accessible forms
- design responsive application layouts

## Integration guides

Backend examples show how application data reaches Frasto without making a provider part of the core component architecture.

## Documentation rule

Examples use real released APIs once available. Planned pages describe structure and ownership without inventing fake exports simply to fill a code sample.
