---
title: Build a CRM
description: Organize contacts, companies, activity, filters, and record workflows with Frasto patterns.
---

## Information architecture

Start with recognizable tasks: Dashboard, Contacts, Companies, Deals, Activities, and Reports. Avoid exposing storage collections as the navigation model.

## Customer list

Compose `PageHeader`, `FilterBar`, `ResourceTable`, and `Pagination`. Define identity columns, status, owner, last activity, and row actions from real user decisions.

## Customer detail

Lead with identity, lifecycle status, and relevant actions. Group contact information, company relationship, deals, invoices, and activity by workflow rather than database tables.

## Activity

Translate domain events into direct human summaries. Preserve actor, timestamp, changed value, and source where it helps explain the record.

## State model

Distinguish no customers, no filtered results, inaccessible records, deleted records, and temporary load failures.

## Master / detail

Use a split view only when rapid record-to-record review outweighs the space needed by the detail workflow. On mobile, preserve list state when the detail becomes a route or full panel.
