**Status: Planned**

`EmptyState` explains why useful content is absent and what action, if any, makes sense next.

## Empty types

| Type | Message focus | Typical action |
| --- | --- | --- |
| first use | what will appear here | create or import |
| no results | active search/filter context | clear or adjust filters |
| no permission | access boundary | request access or return |
| unavailable | temporary/system context | retry or view status |

## Anatomy

- direct title
- short explanation
- one primary relevant action
- optional secondary help
- optional restrained icon or illustration

## Rules

Do not celebrate missing business data with vague copy. Preserve surrounding page context and distinguish empty from loading or error.

## Accessibility

The state participates in heading order, actions use descriptive labels, and dynamic replacement of a previously populated view is announced when necessary.
