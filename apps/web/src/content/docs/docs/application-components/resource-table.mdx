**Status: Planned**

`ResourceTable` displays comparable records with typed columns, row identity, and optional operations.

It composes the presentational [Table](/docs/application-components/table/) foundation. ResourceTable owns typed row and column mapping; Table owns native structure and visual density. Neither layer fetches or mutates records.

## Initial capabilities

- typed columns and rows
- loading, empty, error, and partial states
- row selection and select-all scope
- row actions
- sorting interface
- responsive overflow or transformation

Later work may add column visibility, resizing, pinning, saved views, and advanced bulk behavior.

## Data contract

The component receives rows and column definitions. Sorting may be client-side or controlled by the application; the contract must not assume a network endpoint.

## Semantics

Use an HTML table when information is meaningfully tabular. Column headers identify scope, sortable headers announce direction, and row controls have record-specific accessible names.

## Selection

Selection behavior defines whether “all” means visible rows, the current page, or the full result set. Bulk action patterns must expose that scope.

## Responsive behavior

Supported strategies include horizontal scrolling, priority columns, reduced columns, structured rows, or card conversion. The chosen mode must preserve record identity and actions.

## Long content

Specify wrapping, truncation, minimum column widths, and access to the full value. Real names, IDs, currency, statuses, and localized dates must be tested.
