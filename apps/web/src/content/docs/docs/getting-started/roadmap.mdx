---
title: Roadmap
description: The sequence from documentation foundations to a stable Frasto release.
---

## Phase 0 — Repository foundation

Workspace, documentation application, package foundation, license, product requirements, architecture, design direction, roadmap, and CI foundation.

## Phase 1 — Documentation foundation

Define the complete information architecture, design foundations, technical policies, component inventory, application component contracts, SaaS patterns, and contribution rules.

## Phase 2 — First primitives

Build the first server-rendered actions, form controls, identity, feedback, and structural primitives on the approved token foundation.

## Phase 3 — Interactions

Implement focused progressive enhancements for Tooltip, Select, Dropdown, Dialog, Drawer, Popover, and Tabs.

## Phase 3.5 — SaaS bridge components

**Current priority.** Specify Breadcrumb, Status, the FormField family, and semantic Table boundaries, then implement the three bridge components as documented vertical slices.

## Phase 4 — SaaS components

Build application essentials, the application shell, resource workflows, and product layouts. Phase 4 starts only after the bridge specifications are ready.

## Phase 5 — Reference SaaS

Use a complete mock-data SaaS application to expose missing states, awkward APIs, accessibility gaps, and responsive weaknesses.

## Phase 6 — Public alpha

Publish an installable package with functional docs, core foundations, initial components, examples, tests, and contribution guidance.

Target: `0.1.0-alpha`.

## Stable release

Version 1.0 requires stable APIs, reliable accessibility and responsive behavior, comprehensive documentation, straightforward installation, and evidence that several real SaaS products can be built without major missing foundations.
