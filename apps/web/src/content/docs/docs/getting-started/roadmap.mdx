---
title: Roadmap
description: The sequence from documentation foundations to a stable Frasto release.
---

## Phase 0 — Repository foundation

Workspace, documentation application, package foundation, license, product requirements, architecture, design direction, roadmap, and CI foundation.

## Phase 1 — Documentation foundation

**Current priority.** Define the complete information architecture, design foundations, technical policies, component inventory, application component contracts, SaaS patterns, and contribution rules.

## Phase 2 — Design tokens

Turn approved foundation decisions into production token files covering color, typography, spacing, square geometry, borders, shadow, motion, sizing, and z-index.

## Phase 3 — Core components

Build the first server-rendered primitives and form controls, beginning with components whose contracts are already documented.

## Phase 4 — Interactive components

Implement and validate select, dropdown, dialog, drawer, popover, tabs, and other interaction-heavy components.

## Phase 5 — SaaS components

Build the application layer: shell, navigation, resource views, filters, pagination, detail layouts, settings, and activity.

## Phase 6 — Acme Cloud

Use a complete mock-data SaaS application to expose missing states, awkward APIs, accessibility gaps, and responsive weaknesses.

## Phase 7 — Public alpha

Publish an installable package with functional docs, core foundations, initial components, examples, tests, and contribution guidance.

Target: `0.1.0-alpha`.

## Stable release

Version 1.0 requires stable APIs, reliable accessibility and responsive behavior, comprehensive documentation, straightforward installation, and evidence that several real SaaS products can be built without major missing foundations.
