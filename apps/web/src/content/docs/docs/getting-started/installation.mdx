:::caution[Public alpha]
Frasto components remain Experimental. Breaking changes are possible and production use is not yet recommended.
:::

Install the public alpha from npm's `next` channel:

```bash
pnpm add @freight-px/frasto@next
```

Import components in an Astro component or layout. The package entry automatically includes the compiled Frasto stylesheet:

```astro
---
import { Button, PageHeader } from '@freight-px/frasto';
---
```

## Requirements

- Astro `>=7 <8` is the supported alpha range.
- Frasto's package metadata requires Node.js 22 or later. For fresh Astro 7 installs, use Node.js 22.19 or later to satisfy the current transitive dependency engine requirements.
- Consumers do not need React, Vue, Svelte, or Tailwind.
- Consumers do not need a separate Frasto stylesheet import in the normal setup.
- Static components should not add a client runtime.
- TypeScript definitions ship with the package.

## Working from source

Contributors can run the documentation workspace with:

```bash
pnpm install
pnpm docs:dev
```

Use only components listed in the [available inventory](/docs/components/overview/). Review [project status](/docs/getting-started/status/) before adopting an Experimental API.
