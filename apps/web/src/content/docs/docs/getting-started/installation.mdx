:::caution[Not published yet]
Frasto is in active pre-alpha development. The package is not production-ready and the public API is not stable.
:::

When the public package is available, installation will use:

```bash
pnpm add @freightpx/frasto
```

Import components in an Astro component or layout. The package entry automatically includes the compiled Frasto stylesheet:

```astro
---
import { Button, PageHeader } from '@freightpx/frasto';
---
```

## Requirements

- Astro is the primary supported framework.
- Consumers do not need React, Vue, Svelte, or Tailwind.
- Consumers do not need a separate Frasto stylesheet import in the normal setup.
- Static components should not add a client runtime.
- TypeScript definitions ship with the package.

## Working from source

Contributors can run the documentation workspace with:

```bash
pnpm install
pnpm docs:dev
```

Use only components listed in the [available inventory](/docs/components/overview/), and do not rely on Experimental APIs in production code.
