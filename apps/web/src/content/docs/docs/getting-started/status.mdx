title: Project status
description: The current public maturity of Frasto UI.
---

Frasto UI **public alpha `0.1.0-alpha.1` is available** on npm's `next` channel. It was published on September 3, 2026; all 35 component families remain Experimental.

The package contains 35 Experimental component families across actions, forms, display, feedback, disclosure, navigation, overlays, data presentation, and layout. Phase 5 hardening now includes rendered semantic contracts, Chromium/Firefox/WebKit behavior checks, automated accessibility scans, narrow and touch-oriented evidence, overlay collision and scroll checks, and a packed-package consumer that renders every public family.

## What Experimental means

- implementations are available for evaluation
- APIs may change without migration support
- accessibility and responsive behavior are still being hardened
- manual assistive-technology and real-project evidence is not complete
- the package is not recommended for production-critical use

## Alpha evidence boundary

The September 3 release validation records passing rendered and cross-browser tests, packed-package checks, and human keyboard and visual smoke reviews. Automated accessibility checks do not establish screen-reader support.

Manual Windows NVDA and VoiceOver review, broader physical-device coverage, and real-project evidence remain incomplete and are tracked as post-alpha hardening work. No component has advanced to Beta.

Public release status and available APIs are maintained in this documentation. Draft milestones, planned components, and maintainer working notes remain private until they become accepted public work.
