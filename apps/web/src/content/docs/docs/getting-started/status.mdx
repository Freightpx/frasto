Frasto UI is in **active pre-alpha development**.

The package contains an Experimental set of actions, form controls, display components, feedback, navigation, overlays, data presentation, and layout components. The design tokens, documentation site, and server-first package foundation are also active.

## What Experimental means

- implementations are available for evaluation
- APIs may change without migration support
- accessibility and responsive behavior are still being hardened
- the package is not yet recommended for production use

## Public alpha

Frasto will move toward public alpha after the component inventory is broad enough to be useful, existing APIs are consistent, documentation matches implementation, and accessibility and responsive checks are repeatable.

Development milestones, planned components, and future ecosystem work are tracked separately in the [GitHub development roadmap](https://github.com/Freightpx/frasto/blob/main/docs/project/roadmap.md).
