## Current phase

**Phase 3.5 — SaaS bridge components.**

The repository currently includes:

- product scope
- design principles
- semantic color direction
- typography hierarchy
- spacing and shape rules
- motion and accessibility baselines
- server-first architecture
- package boundaries
- Experimental Phase 2 primitives and Phase 3 interactions
- a working documentation site and SaaS demo
- Experimental Phase 3.5 Breadcrumb, Status, and FormField bridge components
- the semantic Table specification required before Phase 4A
- complete documentation information architecture
- planned application component contracts and milestone boundaries
- pattern and recipe structure

## Not ready yet

The UI package is not production-ready. Pages marked **Planned** describe intended scope, not released APIs. Component APIs remain unstable until implementation and validation advance their status.

## Status language

| Status | Meaning |
| --- | --- |
| Planned | Purpose and scope are documented; implementation has not started. |
| Designing | API, states, and behavior are under active review. |
| Experimental | An implementation exists and may change without migration support. |
| Beta | Suitable for feedback; breaking changes remain possible. |
| Stable | Documented, tested, accessible, and covered by versioning policy. |
| Deprecated | Supported temporarily with a documented replacement path. |

## Alpha target

`0.1.0-alpha` should include the first coherent primitive set, documentation, a reference SaaS screen set, accessibility checks, and an installable package.
