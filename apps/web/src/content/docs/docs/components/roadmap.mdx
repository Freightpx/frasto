## Status model

| Status | Entry criteria |
| --- | --- |
| Planned | repeatable use case and intended scope documented |
| Designing | API, anatomy, states, accessibility, and responsive behavior under review |
| Experimental | implementation available; change expected |
| Beta | documented and testable; feedback requested |
| Stable | API reviewed, accessible, responsive, tested, and versioned |
| Deprecated | replacement and migration path documented |

## Definition of done

A component is not complete when it only renders. Stable components require documented purpose, states, responsive behavior, accessibility, API, and examples.

## Current state

All Phase 2 primitives, Phase 3 interactions, and Phase 3.5 bridge components are **Experimental** package exports. The presentational Table boundary is **Designing** and remains unimplemented until Phase 4A. Other application components remain **Planned**.
