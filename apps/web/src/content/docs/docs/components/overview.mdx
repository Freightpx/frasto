Frasto components are Astro-first, server-rendered by default, TypeScript-safe, backend-agnostic, and designed to compose with native HTML.

:::caution[Experimental library]
Every currently available component is Experimental. APIs may change before public alpha, and Frasto is not yet recommended for production use.
:::

## What component pages include

Each page documents the component's purpose, import, usage, API, accessibility behavior, responsive behavior, and relevant states. If a component is not listed here, it is not part of the current public package inventory.

Planned specifications and contributor roadmaps live in the [GitHub development documentation](https://github.com/Freightpx/frasto/tree/main/docs) so proposed APIs are not confused with available functionality.
