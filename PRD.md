# Product Requirements — Frasto UI

## Product

An Astro-first open-source design system for SaaS dashboards, admin panels, CRM, CMS, ERP-style interfaces, and internal tools.

## Positioning

More application-oriented than a primitive component library, but intentionally smaller in scope than a full application framework.

## Core promise

Give Astro developers reusable components **and** application patterns such as resource lists, filters, settings layouts, detail screens, and app shells without requiring a React runtime.

## Primary users

- Astro developers
- indie SaaS developers
- agencies
- full-stack developers building internal/business software

## Requirements

- Astro-first
- server-rendered by default
- minimal JavaScript
- accessible
- backend agnostic
- themeable with semantic tokens
- light/dark modes
- responsive application patterns
- production-quality documentation

## Non-goals

- database ORM
- authentication framework
- billing system
- backend framework
- marketing-template collection
- generic Tailwind snippet library

## MVP

Approximately 20–30 core components, 10–15 SaaS-oriented components, 4–6 patterns, one complete mock SaaS demo, documentation, and an npm package.
